# Lotus-Yunzai 群功能

这个模块提供 QQ 资料卡点赞。群聊或私聊发送 `#赞我` 或 `#资料卡点赞`，会请求当前协议端给发送者点赞。在群聊发送 `#赞他` 并实际 @ 一位其他群成员，可以给对方点赞。`#全部赞我` 只在群聊处理。每次指令在当前机器人连接上最多提交一次。

主仓的 `config/group.yaml` 可配置点赞。旧 `plugins/yenai-plugin/config/config/thumbUp.yaml` 存在时会补充主配置中省略的字段。也可用 `LOTUS_GROUP_CONFIG` 指向单独的 YAML 文件。两个文件都没有对应值时使用下列默认值。

| 字段 | 默认值 | 用途 |
| --- | --- | --- |
| `enable` | `true` | 启用点赞 |
| `cloneAllThumbUp` | `false` | 设为 `true` 时关闭 `#全部赞我` |
| `strangeThumbUp` | `true` | 设为 `false` 时仅处理协议端确认的好友 |
| `count` | `10` | 每次请求的点赞数，取值 1–10 |
| `recall` | `0` | 回复撤回秒数，取值 0–120；旧配置未设置时沿用 20 秒 |

可用 `closeTips`、`successMsg`、`failsMsg` 和 `noFriendMsg` 自定义提示。空文本或 `false` 不发送提示。`{{at}}` 在群聊提及点赞目标。`{{userId}}` 在给自己点赞时显示「你」，给群成员点赞时显示其 QQ 号。`{{doType}}` 和 `{{thumbUpNum}}` 分别是操作名称和协议端确认的数量。`{{noFriend:…}}` 内的文字只在确认目标非好友时显示。正常的点赞回执可用 `{{img}}` 插入本机生成的表情图。表情图生成失败时仍发送文字提示。

历史指令与开关以椰奶插件的资料卡点赞功能为参考。本模块实现基于 Lotus-Yunzai 的协议能力。

## 主动复读

机器人主人发送 `#复读` 后，机器人提示当前发送者继续输入。接下来同一会话中的下一条消息会按消息段复读，并请求适配器在 5 秒后撤回。不同用户或不同会话的消息各自独立。

## 进退群通知

新人入群时发送欢迎和群公告提示，成员离开或被移出时发送对应通知。支持群名、昵称和头像，具体字段取决于协议端。入群事件缺少群名时会尝试向协议端查询，未查到则显示「本群」。头像发送失败时保留文字与已有的提及。每群欢迎消息间隔至少 30 秒，使用 Valkey 时沿用旧版冷却键。未连接 Valkey 时在当前进程内记录冷却。

## 群聊屏蔽词

屏蔽词监听默认关闭。机器人主人可用 `#抽卡设置屏蔽词开启` 和 `#抽卡设置屏蔽词关闭` 切换。`config/group-screened-words.yaml` 的 `time` 设置禁言秒数，默认 60 秒。`replyText` 设置撤回与禁言均确认后的回复。

群聊发送 `#屏蔽本群 词语`、`#解除屏蔽本群 词语` 和 `#屏蔽词列表` 管理或查看词表。多个词用逗号隔开。普通群管理员的操作只影响本群，机器人主人可用 `全局` 明确操作全局词表。迁移会保留旧版的全局和分群词表、开关和回复设置。[原 Flower 插件](https://gitee.com/Nwflower/flower-plugin)
